# Proyecto: Árbol de Expresión

## Descripción
Este proyecto implementa un programa en Java que permite:

- Validar expresiones matemáticas
- Convertir de notación infija a postfija
- Evaluar expresiones con variables
- Construir un árbol de expresión
- Mostrar el árbol gráficamente

## Ejemplo

Entrada:
a + b * (c - d)

Valores:
a = 2
b = 3
c = 10
d = 4

Resultado:
20

## Tecnologías
- Java
- Swing
- NetBeans
